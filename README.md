# TG Installations Maroc

Application mobile-first pour piloter les installations de Têtes de Gondole (TG) dans les magasins au Maroc.

## Déploiement
Application Next.js App Router, TypeScript, PostgreSQL / Prisma, authentification par identifiant et mot de passe et téléversement des photos d'installation.

## Configuration Vercel
Configurez les variables d'environnement listées dans `.env.example` avant d'exécuter les migrations et le seed.
N'ajoutez jamais de mots de passe en clair ni de clés de service au dépôt.

## Documentation
Consultez la documentation du dépôt pour les étapes d'installation et de déploiement.
